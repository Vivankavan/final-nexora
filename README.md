# NEXORA
**Your learning. Your progress. Your future.**

A colourful, responsive student academic management demonstration site.

## Run
Extract the ZIP and open `index.html` in a modern browser. Internet access is used for fonts, icons and charts.

## Deploy to Netlify (quickest)
1. Extract `Nexora-Source-and-Netlify.zip`.
2. Open https://app.netlify.com/drop
3. Drag the extracted `Nexora` folder (the folder containing `index.html`) into the drop area.
4. Wait for Netlify to publish and copy the generated live URL.

## GitHub
1. Go to https://github.com/new and create a **Public** repository named `nexora`.
2. Upload `index.html` and `README.md` from this folder and commit.
3. Copy the public repository URL.

## Included
Dashboard, Learning Studio, Topic Tracker, demo AI Study Assistant, Notes, Flashcards, Study Techniques, Focus Timer, Exam Performance, Attendance, Assignments, Timetable, Analytics, sample Leaderboard, Profile & Settings, local browser persistence and JSON export.

## Important demo limitations
This is a frontend-only college demonstration build. It has no real AI API, cloud database, login/authentication or real multi-user leaderboard. The AI helper uses clearly labelled sample guidance. Data is saved in the browser's local storage and will not automatically sync between devices. External CDN resources are used for typography, icons and charts.
